\doxysubsection{Detailed Description}
ICM20948 driver header file. 

This file defines the public interface for interacting with the ICM-\/20948 IMU. It must be used in conjunction with a platform-\/specific implementation of the low-\/level I2C access functions defined in icm20948\+\_\+port.\+h.
