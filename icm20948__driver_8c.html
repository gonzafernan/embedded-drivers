bool icm20948_is_device_available ( icm20948_t *  self)

Check if the ICM-20948 IMU is available.

This function checks if the ICM-20948 IMU is available by reading the WHO_AM_I register. If the value matches the expected value, the IMU is considered available.

Parameters
selfPointer to the ICM-20948 IMU structure.
Returns
true if the IMU is available, false otherwise.
